Setup
01

Get at least one free API key

Claude: console.anthropic.com · Gemini: aistudio.google.com · Groq: console.groq.com

02

Set environment variables

export ANTHROPIC_API_KEY=sk-ant-...   export GEMINI_API_KEY=AIza...   export GROQ_API_KEY=gsk_...

03

Run the server

node server.js — then open http://localhost:3000

04

Pick a model and analyze

Select Claude, Gemini, or Groq from the header, type a weak prompt, and see the NLP breakdown + optimized versions.

What is RLHF?

Reinforcement Learning

RLHF trains AI models using human preferences — people compare responses and pick the better one, shaping the model over millions of ratings.

This App Simulates It

Your 👍/👎 ratings build a preference profile. The RLHF dashboard shows which prompt style (Structured, Role-Framed, CoT) you rate highest.

Tech Stack
Backend: Node.js built-in http/https
Zero deps: No npm install needed
Claude: api.anthropic.com/v1/messages
Gemini: generativelanguage.googleapis.com
Groq: api.groq.com/openai/v1/chat
Frontend: Vanilla JS + CSS
